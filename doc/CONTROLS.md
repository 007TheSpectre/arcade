# 🎮 Contrôles de l'Arcade

Cette page détaille de façon exhaustive les contrôles globaux permettant de naviguer dans l'Arcade, de basculer de module à chaud, ainsi que les commandes de base pour jouer aux jeux.

## 1. Déplacements & Actions de base

Ces touches sont utilisées pour vous déplacer dans les menus et interagir à l'intérieur des jeux :

- **Flèche Haut** / **Z** : Aller vers le haut
- **Flèche Bas** / **S** : Aller vers le bas
- **Flèche Gauche** / **Q** : Aller à gauche
- **Flèche Droite** / **D** : Aller à droite
- **Espace** : Action secondaire
- **Entrée** : Action principale / Valider dans le Menu

## 2. Contrôles Généraux & Core

Ces contrôles agissent directement sur le Core de l'Arcade pour la gestion de la session en cours :

- **R** : Redémarrer le jeu actuel (`RESTART`)
- **M** : Revenir au menu principal (`MENU`)
- **Échap (ESC)** : Quitter l'Arcade (`EXIT`)

## 3. Changement Dynamique

La borne d'arcade peut basculer dynamiquement d'une technologie d'affichage ou d'un jeu à un autre. Utilisez ces touches raccourcis :

- **F1** : Passer à la librairie graphique **suivante** (`NEXT_GRAPHIC`)
- **F2** : Passer à la librairie graphique **précédente** (`PREV_GRAPHIC`)
- **F3** : Passer au jeu **suivant** (`NEXT_GAME`)
- **F4** : Passer au jeu **précédent** (`PREV_GAME`)
